| 错误号码   | 日志消息           | 含义与处理方法                                                                                                                                         |
|--------|----------------|-------------------------------------------------------------------------------------------------------------------------------------------------|
| E-0E80 | 指定的文件夹 / 文件名错误 | 可能是因为下列原因所致。 → 指定的全路径的开头字符是'（空白）'。 → 包含有指定的全路径中不存在的文件夹。 → 指定的全路径包含有 ASCII 代码以外的代码。 → 文件打开、以及文件输入输出中，指定的全路 径是已经存在的文件夹。 → 文件删除中，指定的全路径是已经存在的文件 夹。 |
| E-0E81 | 文件存在指定的文件夹里    | 删除文件夹时，指定的文件夹内存在文件。                                                                                                                             |
| E-0E82 | 根文件夹不能被删除      | 无法删除根文件夹。                                                                                                                                       |
| E-0E84 | 文件夹 / 文件已经存在   | 可能是因为下列原因所致。 → 文件夹名 / 文件名变更中，已经存在与变更后同 名的文件夹 / 文件。 → 打开写入用的文件时，同名的文件已经存在， 该文件属性为写保护属性。                                                          |
| E-0E85 | 没找到指定的文件夹 / 文件 | 可能是因为下列原因所致。 → 文件删除、或者文件夹名 / 文件名变更中，不存 在指定的全路径的文件夹 / 文件。 → 读入用的文件打开、或者文件输入中，不存在 指定的全路径的文件。                                                      |
| E-0E86 | USB 设备容量不足     | USB 设备容量不足，因而未能继续进行处理。                                                                                                                          |
| E-0E87 | USB 设备不正常      | 未能正确识别 USB 设备。 请勿在电脑上使用快速格式化选项，而要以 ' FAT '或者' FAT32 '对 USB 设备重新进行格式 化处理后使用。即使这样若还是发生本错误，则更 换 USB 设备。                                            |
| E-0E88 | 拒绝访问           | 可能是因为下列原因所致。 → 在文件夹/文件删除中，指定的文件夹/文件属 于写保护属性。 → 在文件删除中，指定了已经打开中的文件。 → 在文件打开中，指定了已经打开中的文件。（试 图双重打开。） → 以写入用的方式打开文件，读入了文件。 → 以读入用的方式打开文件，写入了文件。    |
| E-0E8D | 超过了文件大小的访问     | 文件指针设定中，试图存取非法的位置。                                                                                                                              |
| E-0F40 | 发生了过电流         | USB 设备有可能被破坏。 发生本错误时，请重新接通 CNC 的电源。若频繁 发生本错误，则更换 USB 设备。                                                                                        |
| E-0F41 | 发生了奇偶校验错误      | 主板有可能被破坏。 发生本错误时，请重新接通 CNC 的电源。若频繁 发生本错误，则更换主板。                                                                                                 |
| E-XXXX | （没有消息）         | 内部错误。 请向我公司联系错误号码。                                                                                                                              |
