## 错误和日志消息

## 注释

各日志消息，有时同时输出日志消息详细 "[Ch(n):XXX]" 。 问题解决不了时，请连同日志消息以及日志消息详细，向我公司联系。

| 错误号码                        | 日志消息             | 含义与处理方法                                                                                                                                                                                                                                                              |
|-----------------------------|------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| E-0E02                      | 超出了可以打开的文件数      | 可同时打开的文件数至多为 60 个。                                                                                                                                                                                                                                                   |
| E-0E03                      | 检索的文件正在运行中       | 无法同时执行多个文件搜索。 文件搜索中，有可能试图在结束文件搜索之前开始 别的文件搜索。                                                                                                                                                                                                                         |
| E-0E04                      | 没找到检索的文件         | 在指定的全路径的文件夹内，没有找到指定搜索的 文件 / 文件夹。                                                                                                                                                                                                                                     |
| E-0E05                      | 指定的驱动器名不正确       | 无法指定 A 驱动器以外的。                                                                                                                                                                                                                                                       |
| E-0E06                      | 不能使用 FORFANUC    | 在全路径指定中，像' A:\FORFANUC( 任意文 字 )\ ···'那样，无法对根文件夹内的开头 8 个 字符指定 "FORFANUC" 。                                                                                                                                                                                            |
| E-0E07                      | 超出了可以指定的文件夹层数    | 可以识别的文件夹层数最多为 6 层。可能是因为下 列原因所致。 → 在文件夹创建、文件夹删除、或者文件一览取 得中，在全路径中指定了第 7 层的文件夹。 譬如，不可进行像 "A:\DIR1\DIR2\DIR3\DIR4\DIR5\DIR6\DIR7" 那样的全路径指定。 → 在文件删除、文件夹名 / 文件名变更、文件打开、 文件搜索、或者文件输入输出中，全路径中指 定了第 7 层内的文件。 譬如，不可进行像 "A:\DIR1\DIR2\DIR3\DIR4\DIR5\DIR6\DIR7\ ABC" 那样的全路径指定。 |
| E-0E08 E-0E09 E-0E0A        | USB 设备正在使用中      | 无法执行格式化处理。可能是因为下列原因所致。 → 存在打开中的文件。 [E-0E08] → 正在进行文件搜索。 [E-0E09] → 上述以外，正在向 USB 设备进行存取。 [E-0E0A]                                                                                                                                                                     |
| E-0E0E E-0E0F E-0E13 E-0E14 | 正在使用的 USB 设备被拔出了 | 可能是因为下列原因所致。 → 文件打开中，暂时拔出 USB 设备，进行再连接 后，执行了文件操作（文件写入、文件关闭等）。 这种情况下，文件的信赖性将得不到保证。 [E-0E0E, E-0E13] → 文件搜索中暂时拔出 USB 设备，进行再连接 后，继续进行文件搜索，或者文件搜索已结束。 [E-0E0F, E-0E14]                                                                                                   |
| E-0E12                      | （没有日志消息）         | 文件一览获取中，排序失败。 有可能在文件一览获取中，别的应用程序（ C 语言 执行器等）进行了文件夹 / 文件的追加、或者删除。 请在显示文件一览的画面上进行再显示。                                                                                                                                                                                  |
| E-0E40                      | 没有插入 USB 设备      | 尚未识别 USB 设备。可能是因为下列原因所致。 → 尚未插入 USB 设备， 或者在识别 USB 设备前试 图进行存取。 → USB 设备存取中拔出了 USB 设备。                                                                                                                                                                                 |
| E-0E41                      | USB 设备正在格式化      | 试图在 USB 设备的格式化处理过程中对 USB 设备 执行其他操作。请在格式化处理结束后进行操作。                                                                                                                                                                                                                   |
